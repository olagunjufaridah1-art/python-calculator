# Python Calculator

## Description
This is a simple calculator built using Python. It performs basic arithmetic operations like addition, subtraction, multiplication, and division.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User input handling

## How to Run
1. Download the file
2. Open terminal
3. Run:
   python calculator.py
